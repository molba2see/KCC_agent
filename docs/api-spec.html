구현 기준: Django 모델·URL·시리얼라이저·OpenAPI · 2026-11-06 · API v0.1.0

클라우드는 상태와 명령을 중계하고, 파일 작업은 Mac이 실행합니다.

웹 요청은 세션 쿠키를 사용합니다. 변경 요청에는 CSRF 쿠키와 X-CSRFToken을 함께 보내세요. 로그인·가입 후에는 CSRF 토큰을 다시 조회합니다. Mac 브리지는 Authorization: Bearer <bridge_token>을 사용합니다.

API 접두사: /api/v1/ · 목록은 페이지당 30개, ?page=2로 다음 페이지 조회.
클라우드: 운영 Swagger · 로컬: http://127.0.0.1:8000 · OpenAPI JSON 내려받기 · 전체 ERD (Mermaid) · 공통 스키마 정의

/files/와 /reviews/는 DB 메타데이터용입니다. 실제 Mac의 상태는 /agent/status/, 파일 작업은 /agent/commands/를 사용합니다. /local/*는 설치된 Mac에서만 동작하며 운영 서버에서는 404입니다. Apple 로그인은 별도 개발자 설정이 필요합니다.
