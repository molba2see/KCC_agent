# 회원가입 → Mac → iPhone 온보딩

진입 주소: `https://3.38.192.19/#signup` / 가이드 재개: `https://3.38.192.19/#onboarding`

0. **Dock에 추가**: Mac Safari에서 파일 → Dock에 추가 → 이름 모아 AWS → 추가를 안내합니다. Dock 아이콘으로 앱을 연 뒤 가입·로그인을 진행합니다. 앱 모드가 감지되거나 사용자가 이미 추가했다고 확인하면 이 안내를 건너뜁니다. 미지원 환경에서는 브라우저로 계속할 수 있습니다.
1. **모아 계정 만들기**: 아이디·선택 닉네임·비밀번호·확인 입력. 가입 후 자동 로그인하여 온보딩으로 이동합니다. Apple 개발자 가입은 필요 없습니다.
2. **Mac 연결**: AWS 화면의 **모아 연결 앱 다운로드**에서 ZIP을 받고 압축을 풀어 **Moa Helper** 앱을 한 번 엽니다. 앱이 Python과 연결 프로그램을 자동으로 설치합니다. AWS의 `이 Mac 연결`에서 링크를 발급받고 도우미에서 승인합니다. 도우미에서 iCloud Drive를 연결하면 모아 전용 폴더를 만들고 AWS에 상태를 전송합니다. 돌아오기 링크는 AWS 온보딩을 엽니다.
3. **iPhone 설정**: Mac의 웹 화면은 그대로 두고 iPhone의 설정·파일 앱만 사용합니다. iPhone에서 모아에 로그인할 필요는 없습니다. Mac과 같은 Apple 계정인지 확인하고 iCloud Drive의 `이 iPhone 동기화`를 켭니다. 파일 앱에서 `iCloud Drive/KCC-inbox`를 확인한 뒤 `KCC-inbox 폴더가 보여요`를 누릅니다. 이 항목은 사용자 확인이며 웹에서 Apple 계정을 조회하지 않습니다.
4. **전송 테스트**: 폴더 확인 버튼을 누르면 테스트가 자동으로 시작됩니다. 이후 Mac 화면의 QR을 iPhone 카메라로 스캔 → 모아 설치 안내 → [공유 단축어](https://www.icloud.com/shortcuts/2e21efc91f794f02af4821c98ac64069) 추가 → 설정/손쉬운 사용/터치/뒷면 탭에서 `알림 보기` 단축어 지정 → 개인정보 없는 화면에서 뒷면 탭으로 캡처합니다. 단축어는 `iCloud Drive/KCC-inbox`에 저장합니다. Mac을 켜두고 동기화를 기다립니다. 새 파일이 수신되면 파일명을 표시하고 완료 버튼을 활성화합니다.
5. **시작하기**: `좋아요, 설정 마치기 → 내 파일 보러 가기`에서 완료를 저장하고 모든 파일 화면으로 이동합니다. Mac Safari의 파일 → Dock에 추가에서 `모아 AWS`로 저장합니다.

Mac에서 켜둔 도우미가 iCloud 파일을 읽고 AWS로 메타데이터를 보냅니다. iPhone에는 에이전트나 별도 앱을 설치하지 않습니다. 수신 검증은 새 파일이 Mac 스냅샷에 들어왔는지를 확인하며, 발신 기기가 iPhone이라는 하드웨어 인증은 제공하지 않습니다. 파일 원본은 KCC-inbox에 남고 작업 사본은 확실한 분류 계획일 때 자동 이동합니다. 애매한 파일은 사용자 결정을 기다리며, 이동은 되돌릴 수 있습니다.

진행 상황은 `library_onboardingprogress` 테이블에 사용자별로 저장합니다. iPhone 설정 확인, 테스트 시작 시각과 기존 파일 ID 목록, 완료 시각을 저장하며 다른 사용자에게 노출하지 않습니다. 같은 모아 계정으로 로그인하면 Mac과 iPhone에서 이어볼 수 있습니다. `나중에 하기`를 선택해도 연결 메뉴의 `Mac · iPhone 연결 가이드`에서 재개할 수 있습니다.

API: `GET/POST /api/v1/onboarding/`. POST action은 `confirm_iphone`, `start_test`, `complete`입니다. 완료는 Mac 온라인·iPhone 설정 사용자 확인·테스트 이후 새 파일 수신 조건을 서버에서 검사합니다. 기존 파일과 다른 사용자의 파일은 테스트 결과에 포함하지 않습니다.

동기화 문제 시 계정 일치, 저장 위치(iCloud Drive와 나의 iPhone 구분), Mac 절전, 도우미 실행, iCloud 다운로드 상태·저장 공간·네트워크를 확인하도록 안내합니다.

Apple 공식 설정 안내: https://support.apple.com/ko-kr/118443

## 화면 구성

한 화면에는 현재 할 일 하나만 표시합니다. Dock 추가 안내 다음 화면에서 iPhone → iCloud 폴더 → Mac·모아 흐름을 설명한 뒤, Mac 연결 / iPhone QR 및 폴더 확인 / 뒷면 탭 캡처 / 자동 수신 확인 / 완료 화면으로 이동합니다. Mac에서 진행할 때 iPhone 웹 로그인을 요구하지 않습니다. 설치와 문제 해결 설명은 해당 화면의 접힌 도움말로 옮겼습니다.

Mac 연결 버튼은 연결 도우미를 새 탭에 엽니다. 기존 iCloud 설정이 있으면 승인 후 AWS 가이드로 돌아오고, 처음이라면 공유 폴더 만들기 버튼을 안내합니다. 별도의 테스트 시작 버튼은 제거했으며, 폴더 확인 후 자동으로 수신 기준을 저장합니다.

## 다운로드와 앱 실행

Mac 연결 단계는 GitHub나 터미널 명령 대신 `/downloads/moa-mac-helper.zip`을 제공합니다. Apple Silicon과 Intel Mac을 모두 지원하며 macOS 14 이상이 필요합니다. 첫 다운로드 후 압축을 풀어 앱을 한 번 실행해야 하며 macOS 실행 확인은 사용자가 승인합니다. 배포본은 임시 서명된 개발용이며 Apple 공증은 아직 없습니다.

설치된 연결 앱은 `moa-helper://connect?ticket=...` 링크로 실행됩니다. 브라우저는 임의의 프로그램을 자동 설치·실행할 수 없으므로 최초 앱 열기와 macOS 승인은 생략할 수 없습니다. 설치 후에는 연결 버튼으로 앱 실행 → localhost 승인 화면까지 이어집니다. 5분짜리 연결 코드는 앱 메모리에서만 처리하며, 셸 인자·로그·설치 파일에 저장하지 않습니다.

앱은 `~/Applications/Moa Helper.app`에 등록하고 실행 소스와 Python은 `~/Library/Application Support/Moa/releases/<hash>`에 보관합니다. Safari Dock 웹앱은 교체하지 않습니다. 브라우저와 Dock 웹앱의 로그인이 분리될 수 있어, 설치 완료 후 기존 Dock 앱으로 돌아가도록 안내합니다.

## iPhone 단축어와 뒷면 탭

공유 단축어 이름은 `알림 보기`이며 스크린샷 촬영, 날짜 기반 이름 변경, iCloud Drive의 `KCC-inbox` 저장을 수행합니다. QR에는 계정 토큰 없이 공개 설치 안내 URL만 넣습니다. 단축어 추가는 사용자가 Apple 단축어 앱에서 승인합니다. 뒷면 탭 배정은 iPhone의 손쉬운 사용 설정이므로 공유 링크로 배포하거나 웹에서 자동 지정할 수 없습니다. 처음 실행할 때 파일 접근 권한 확인이 필요할 수 있습니다.

이 공유 단축어의 저장 액션은 공유자의 iCloud Drive `KCC-inbox` 폴더 참조를 담고 있습니다. 다른 Apple 계정의 iPhone에서 폴더 참조가 그대로 동작하는지는 실제 기기로 확인해야 합니다. 작동하지 않으면 해당 기기에서 저장 액션의 폴더를 자신의 `KCC-inbox`로 다시 지정해야 합니다.
