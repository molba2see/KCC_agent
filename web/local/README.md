# 다운로드로 Mac 연결 앱 설치

AWS 모아의 **모아 연결 앱 다운로드** → ZIP 압축 해제 → **Moa Helper** 앱 열기 순서로 시작합니다. 앱이 Python·실행 환경·파일 에이전트·자동 실행을 준비합니다. 준비 완료 후 기존 Dock의 모아 AWS로 돌아가 **설치한 앱으로 Mac 연결하기**를 누르세요. 이후에는 `moa-helper://` 링크가 연결 앱을 실행합니다.

최초 다운로드한 앱의 실행과 macOS 확인은 사용자가 승인해야 합니다. 현재 개발용 임시 서명 배포본으로 Apple 공증은 없습니다. 설치 로그는 `~/Library/Application Support/Moa/installer.log`입니다.

배포 다운로드는 `python web/local/build_helper.py`로 Apple Silicon·Intel 공용 앱을 만듭니다. 생성 파일은 Git에서 제외되며 AWS 배포 스크립트가 자동으로 빌드해 업로드합니다. 소스 아카이브 SHA-256을 실행 전에 검사하고 로컬 계정·토큰·DB는 배포 파일에 포함하지 않습니다.

# Mac 연결 프로그램 설치

프로젝트의 **모아 시작.command**를 더블클릭하고 **Mac 연결 프로그램이 준비되었습니다**가 나올 때까지 기다립니다. 이어서 AWS 모아의 **이 Mac 연결하기**를 누릅니다. 이 시작 파일은 연결 프로그램만 설치하며 Safari에서 Dock에 추가한 웹앱을 교체하지 않습니다.

캐시 초기화나 자동 실행 해제 후에는 시작 파일을 다시 실행해야 합니다. 연결 프로그램이 꺼져 있으면 localhost 연결 화면이 열리지 않습니다.

기존 로컬 웹앱을 별도로 설치하려면 `.venv-moa/bin/python web/local/install.py`를 실행합니다.

# 기존 로컬 웹앱 안내

1. 저장소를 다운로드한 뒤 최상위 **모아 시작.command**를 더블클릭합니다.
2. 열리는 모아 화면에서 **iCloud Drive 연결**을 누릅니다.
3. 자동으로 설치된 **Dock의 모아 아이콘**으로 엽니다. Swift 컴파일러가 없는 Mac에서는 Safari의 **파일 → Dock에 추가**를 사용합니다.

Python 3.12와 전용 실행 환경, 개인 계정, Mac 실행기는 자동으로 준비합니다. 사용자가 토큰·비밀번호·터미널 명령을 설정할 필요는 없습니다. 첫 설치에는 인터넷이 필요합니다. Python은 uv 공식 설치기로 자동 준비하며, Swift 개발 도구가 없는 Mac은 Safari 웹앱으로 열립니다. 파일이 차단되면 macOS의 개인정보 보호 및 보안에서 설치 파일 실행을 허용해야 합니다. 일반 사용자용 서명·공증된 설치 패키지는 아직 제공하지 않습니다.

연결 시 `iCloud Drive/KCC-inbox`와 `iCloud Drive/모아` 아래의 `문서`, `영수증`, `회의`를 만듭니다. iPhone에서는 공유 단축어가 같은 Apple 계정의 `KCC-inbox`에 스크린샷을 저장합니다. Mac이 켜져 있고 iCloud가 파일을 내려받으면 실행기가 새 파일을 감지합니다. Mac이 꺼져 있을 때 받은 파일도 다음 실행에서 수집합니다. 수집 기록을 로컬에 남겨 재시작 때 같은 파일을 중복 수집하지 않습니다. 원본은 KCC-inbox에 남고 확실한 분류 계획이 나온 작업 사본은 자동으로 프로젝트 폴더로 이동합니다. 애매한 파일은 사용자의 결정을 기다립니다. iCloud 전체를 스캔하거나 Apple 계정 비밀번호를 받지 않습니다.

웹의 iCloud 연결은 Mac에 동기화된 전용 폴더를 사용하는 방식입니다. Apple 로그인, CloudKit, iCloud Drive 전체에 대한 웹 권한 부여는 아닙니다. Drive의 실제 동기화 상태는 macOS에서 확인합니다. Mac이 잠들거나 꺼져 있으면 파일 처리는 멈춥니다.

사용자별 데이터와 비밀키는 `~/Library/Application Support/Moa`에 보관합니다. 로컬 웹은 `127.0.0.1:8000`, 에이전트는 `127.0.0.1:8791`만 사용합니다. 로컬 연결 기능은 설치기가 설정한 환경과 loopback 주소에서만 켜집니다. 최초 앱 실행 링크의 비밀키는 URL fragment로 전달해 서버 요청 로그에 남기지 않고 바로 지웁니다. 이후 로그인은 HttpOnly 세션 쿠키를 사용합니다. 쿠키가 지워졌으면 **모아 시작.command**를 다시 여세요.

현재 규칙 기반 에이전트를 사용하며, GPU 모델·OCR·PDF 변환 도구는 별도 설정입니다. 불명확한 파일은 웹에서 사용자가 프로젝트를 선택하고 계획을 승인합니다.

실행기는 사용자 LaunchAgent `com.moa.local`로 로그인 시 자동 실행합니다. 저장소 폴더를 옮기면 시작 파일을 다시 실행해 경로를 갱신하세요. 오류 로그는 위 데이터 폴더의 `service.log`, `web.log`, `agent.log`, `bridge.log`에 있습니다.

중지·자동 실행 해제:

```sh
launchctl bootout gui/$(id -u)/com.moa.local
rm ~/Library/LaunchAgents/com.moa.local.plist
```

이 작업은 iCloud 파일과 사용자 데이터를 삭제하지 않습니다. Python 업그레이드는 시스템 Python을 바꾸지 않고 사용자 전용 Python 3.12 및 `.venv-moa` 환경을 사용합니다.

## AWS 사이트를 Safari Dock 앱으로 사용

운영 사이트에서 로그인한 뒤 **이 Mac 연결 → Mac 연결 화면 열기**를 선택합니다. 이 Mac의 도우미에서 주소를 확인하고 연결을 승인한 뒤 iCloud Drive를 연결하고 AWS 화면으로 돌아갑니다. Safari **파일 → Dock에 추가**에서 `모아 AWS`로 저장하세요. Apple 로그인 설정과 구체적인 흐름은 [`../backend/APPLE_LOGIN.md`](../backend/APPLE_LOGIN.md)를 참고하세요.

기본 허용 운영 주소는 `https://3.38.192.19`입니다. 운영 도메인이 바뀌면 설치 전에 `MOA_CLOUD_ORIGIN`을 설정해야 하며, 도우미는 등록되지 않은 주소로 연결 코드를 보내지 않습니다. 토큰과 비밀번호를 직접 복사할 필요는 없습니다. 연결 해제는 로컬 화면의 **AWS 연결 해제**에서 수행합니다.
